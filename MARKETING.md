## 4. r/learnprogramming post draft

**Title:** I open-sourced an 8-phase Python lab for learning DSA from scratch — every algorithm runnable, tested, and Big-O annotated

**Body:**

Hey r/learnprogramming,

I built **LuminaPy** (https://github.com/Harery/LuminaPy) because I got tired of recommending the same patchwork of resources to people learning Python + DSA. It's an actual curriculum, not a snippet dump.

**What's in it**
- 8 phases: Foundations → Data Structures → Algorithms → Advanced DS → Patterns → Advanced Algorithms → Challenges → Mastery
- Every implementation is a small Python module you can run, edit, and `pytest`
- Big-O time + space annotated at the top of every file
- 11 interview patterns each with their own README and runnable example
- Cheat sheets (Big-O, patterns, interview checklist, Python tips)
- Jupyter notebooks for visualizations (sorting, BST, DP, graphs)

**What it isn't**
- Not a LeetCode farm
- Not a video course
- Not a "200 algorithms in one file" repo

**Tech**
- Python 3.12+, ruff, pyright, pytest, MkDocs Material, GitHub Codespaces
- GPLv3, free forever

There's a "Pick Your Path" section in the README for beginners / mid-level / interview-cramming / educators. Roast it, file issues, send PRs.

⭐ if it helps.

**Title:** [Resource] Free open-source 8-phase Python DSA lab — patterns + Big-O + tests + one-click Codespace

**Body:**

If you're 2–4 weeks out from a FAANG interview and tired of grinding random LeetCode problems, here's the repo I wish I had:

**LuminaPy** — https://github.com/Harery/LuminaPy

It's organized around the 11 interview patterns that cover ~80% of medium/hard LeetCode questions (Sliding Window, Two Pointers, Fast/Slow, Merge Intervals, Cyclic Sort, Tree BFS/DFS, Two Heaps, Subsets, Modified Binary Search, Top-K, Island/Matrix). CI runs pytest + ruff + pyright on every push, so the code is production-quality, not interview-pad-quality.

Free, GPLv3, one-click Codespace. Useful if you're prepping, mentoring someone who's prepping, or building your own study plan.
